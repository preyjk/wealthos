# WealthOS

**An open-source personal wealth management platform for tracking cash flow, investments, and net worth.**

## Overview

WealthOS is a personal wealth management platform designed to help individuals gain a clear and comprehensive understanding of their financial lives. By bringing cash flow, investments, assets, and liabilities into one place, WealthOS aims to make financial tracking more accessible, organized, and insightful.

## Features

Cash Flow Management:

- Track income and expenses.
- Categorize financial transactions.
- Monitor account balances.

## Tech Stack

**Core Tech Stack:** Next.js + NestJS + PostgreSQL

| Layer    | Technology | Description                                                                        |
| -------- | ---------- | ---------------------------------------------------------------------------------- |
| Frontend | Next.js    | React-based framework for building modern web applications.                        |
| Backend  | NestJS     | Node.js framework for building scalable and maintainable server-side applications. |
| Database | PostgreSQL | Open-source relational database for reliable and structured data storage.          |
